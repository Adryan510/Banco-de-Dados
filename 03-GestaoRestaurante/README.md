# Gestão de Restaurante

Projeto acadêmico desenvolvido na disciplina de Banco de Dados, utilizando MySQL.

## Objetivo

Desenvolver um banco de dados para representar e organizar as operações de um restaurante.

## Estrutura do projeto

- `ModeloFisico.sql` — estrutura do banco de dados e criação das tabelas.
- `Inserts.sql` — inserção de dados para testes.
- `Consultas.sql` — consultas SQL desenvolvidas no projeto.
- `Diagrama-EER.png` — diagrama Entidade-Relacionamento.

## Tecnologias utilizadas

- MySQL
- SQL

## Status

Projeto acadêmico.
