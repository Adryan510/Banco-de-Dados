# Gestão de Restaurante

Projeto acadêmico desenvolvido na disciplina de Banco de Dados, utilizando MySQL.

## Objetivo

Modelar e organizar um banco de dados para representar as operações de um restaurante.

## Estrutura do projeto

- `02_Dados_e_Consultas_Gestao_Restaurante.sql` — inserção de dados de teste e 18 consultas SQL.
- `Diagrama-EER.png` — representação visual do modelo Entidade-Relacionamento.
- `Gestao_Restaurante.mwb` — arquivo editável do modelo no MySQL Workbench.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## Conteúdo estudado

- Modelagem de banco de dados.
- Relacionamentos entre tabelas.
- Inserção e consulta de dados.
- JOIN, GROUP BY e HAVING.
- Subconsultas e funções de agregação.

## Observação

O script de criação das tabelas não está incluído nesta versão do projeto.
