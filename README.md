# Banco de Dados

Repositório destinado aos projetos e atividades desenvolvidos na disciplina de Banco de Dados.

## Objetivo

Aplicar os conceitos de modelagem de dados, criação de tabelas, relacionamentos e consultas SQL utilizando sistemas de gerenciamento de bancos de dados.

## Tecnologias utilizadas

- MySQL
- SQL
- GitHub

## Projetos desenvolvidos

### 1. Sistema de Reserva de Carros

Banco de dados para gerenciamento de sedes, veículos, clientes, classes de carros e reservas.

**Conteúdos aplicados:**
- Criação de banco de dados e tabelas.
- Chaves primárias e estrangeiras.
- Relacionamentos entre tabelas.
- Integridade referencial.

**Arquivo:** `SistemaReservaCarros.sql`
